# AutoBooks downloads

Windows early-access installers and checksums for AutoBooks.

Visit https://autobooks-web-production.up.railway.app/download for setup instructions.

This repository contains distribution assets, not the application or backend source.
The installer is unsigned. Use scratch data and supervise tasks. Current hosting is
an owner prototype with Stripe sandbox subscriptions and a limited shared AI budget.

The installer includes its application license and third-party notices. Download
SHA256SUMS.txt alongside the installer to verify the file.
